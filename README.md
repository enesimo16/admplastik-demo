# admplastik

Kurumsal web sitesi kaynak kodu (PHP).

## Kurulum

PHP ve MySQL gerekir. Veritabanı ve ayar dosyaları bu depoda yer almaz.

## Notlar

- Yönetim paneli (`adminx`), veritabanı dökümü ve iç belgeler depoya dahil değildir.
- API anahtarları yer tutucuyla değiştirilmiştir (`CHANGE_ME`, `YOUR_GOOGLE_MAPS_KEY`).
